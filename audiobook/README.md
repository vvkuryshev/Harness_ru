## Запуск

Скрипт лежит в корне проекта: `make_audiobook.py`. Запускать из папки проекта:

```bash
python3 make_audiobook.py --part intro    # Введение
python3 make_audiobook.py --part part0    # Часть 0
python3 make_audiobook.py --part part1    # Часть I
# ... part2 .. part6 (части II–VI)
```

Пресеты скрипта (диапазоны строк в курсе `README.md`):

| Пресет | Раздел | Строки |
|---|---|---|
| `intro` | Введение | 91–399 |
| `part0` | Часть 0. Теоретическая база | 403–715 |
| `part1` | Часть I. Фундамент | 717–971 |
| `part2` | Часть II. Состояние и время | 973–1131 |
| `part3` | Часть III. Скоуп и дисциплина | 1133–1310 |
| `part4` | Часть IV. Верификация | 1312–1549 |
| `part5` | Часть V. Эксплуатация | 1551–1758 |
| `part6` | Часть VI. Автономия | 1760–2130 |

Произвольный кусок текста:

```bash
python3 make_audiobook.py --start 91 --end 399 --title "Книга. Мой раздел." --name Custom_Name
```

Полезные флаги: `--voice` (другой голос), `--rate` (например `+4%`).

## Требования

- Python 3, `ffmpeg` (brew install ffmpeg), интернет.
- `edge-tts` не нужен заранее — скрипт сам создаст venv `.venv-tts/` в корне проекта и установит его. Можно переопределить: `EDGE_TTS=/путь/к/edge-tts python3 make_audiobook.py --part intro`.

## Примечания

- Промежуточные файлы (текст, аудио глав, WAV) — в `audiobook/.work/`, можно удалять.
- Перегенерация: просто запустить заново — файлы перезапишутся.
- Медленные разделы (практика, задачник) озвучивать по частям через `--start/--end`.

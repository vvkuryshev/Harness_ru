## Как слушать

Нажмите на любой MP3-файл — GitHub проигрывает аудио прямо на странице файла, без скачивания. Файлы также можно скачать (кнопка Download raw file) и слушать офлайн.

## Сгенерировать аудиокниги самостоятельно

Все файлы собраны скриптом [`make_audiobook.py`](../make_audiobook.py) из текста курса. Если вы форкнули репозиторий и обновили текст — так же просто обновить и озвучку.

Требования: Python 3, `ffmpeg` в PATH, интернет. Зависимость `edge-tts` ставить не нужно — скрипт сам создаст виртуальное окружение `.venv-tts/` и установит её.

Запуск из корня проекта:

```bash
python make_audiobook.py --part intro    # Введение
python make_audiobook.py --part part0    # Часть 0. Теоретическая база
python make_audiobook.py --part part1    # Часть I. Фундамент
# ... part2–part6 — части II–VI
```

Полезные флаги:

- `--voice <голос>` — другой голос TTS (например, мужской);
- `--rate "+4%"` — скорость чтения;
- `--start N --end M` — озвучить произвольный кусок курса по номерам строк в `README.md`.

Промежуточные файлы попадают в `audiobook/.work/` — их можно удалять без последствий. Повторный запуск перезаписывает готовые MP3.
